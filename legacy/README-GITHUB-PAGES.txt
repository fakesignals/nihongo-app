[업로드할 위치]
아래 파일들을 GitHub 저장소의 최상위(root)에 그대로 올리세요.
- index.html
- manifest.json
- sw.js
- icon-180.png
- icon-512.png
- .nojekyll

[GitHub Pages 켜기]
1. GitHub 저장소 → Settings
2. 왼쪽 Pages
3. Build and deployment → Source: Deploy from a branch
4. Branch: main / Folder: /(root)
5. Save
6. 표시되는 https://계정.github.io/저장소명/ 주소를 엽니다.

[iPhone 설치]
1. 위 주소를 반드시 Safari에서 엽니다.
2. 공유 버튼(□↑) → 홈 화면에 추가
3. 홈 화면의 '일본어 노트' 아이콘으로 실행합니다.

[데이터]
단어/학습기록은 해당 iPhone Safari/PWA의 브라우저 저장공간에 저장됩니다.
기기 변경·브라우저 데이터 삭제에 대비해 앱의 백업 기능으로 JSON을 가끔 저장하세요.
